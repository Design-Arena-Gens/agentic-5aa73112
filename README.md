## Aurora Vault — Independent Cinema Network

A single-page streaming showcase built with **Next.js 15**, **React**, and the new **Tailwind CSS v4** syntax. Aurora Vault highlights curated documentaries, animations, and travel shorts with a featured video hero and dynamic filtering.

### Features

- Featured video player with metadata overlays
- Genre filtering and keyword search across the curated catalogue
- Responsive layouts with animated gradients and soft-glass panels
- Tailwind CSS theme tokens and Next.js App Router architecture

### Running Locally

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to explore the experience.

### Production Build

```bash
npm run build
npm run start
```

### Deployment

The project is ready for zero-config deployment on Vercel. A production build is required before running the provided deployment command.
